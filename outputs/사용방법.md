# Morning Signal 사용방법

1. 앱을 열면 맨 위의 **오늘의 핵심 결론 3개**를 먼저 읽습니다.
2. 시간이 있으면 **오늘 꼭 볼 뉴스**에서 요약과 `왜 중요한가`를 확인합니다.
3. 상세 분석을 펼치면 긍정·주의 시나리오와 앞으로 볼 지표가 나옵니다.
4. 주제 버튼으로 AI·글로벌 기술주, 삼성전자·SK하이닉스, 부동산·대출, 관심 지역만 골라봅니다.
5. `관심 있음` 또는 `관심 없음`을 누르면 이 기기에서 다음 정렬에 보조 신호로 사용됩니다.
6. `최신 뉴스 반영하기`를 누르면 아침판은 유지되고 이후 이슈만 **새로 추가된 주요 뉴스**에 나타납니다.
7. 출처 이름을 누르면 정부·기업·언론의 원문 페이지가 새 창에서 열립니다.

현재 첫 버전은 기능 검증을 위한 샘플 브리핑을 사용합니다. 실시간 뉴스 수집 연결은 다음 확장 단계입니다.
