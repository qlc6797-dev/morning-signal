# 개인 맞춤 뉴스 브리핑 MVP 설계

## 목표

매일 아침 30초에서 10분 안에 투자와 부동산의 핵심 흐름을 파악할 수 있는 개인용 브리핑 웹앱을 만든다. 모바일에서 빠르게 읽고, PC에서는 넓은 화면으로 같은 내용을 편하게 검토한다.

## 검토한 접근

1. **브라우저 로컬 MVP — 채택.** 실감 나는 샘플 이슈와 교체 가능한 데이터 모듈을 사용하고, 관심 반응과 새로고침 상태는 기기에 저장한다. 계정과 서버 없이 즉시 실행할 수 있고 승인된 첫 버전 범위에 가장 잘 맞는다.
2. **실시간 뉴스 API 직접 연결.** 최신성은 높지만 API 키, 과금, 출처별 약관, 수집 실패 처리와 서버 비밀 관리가 필요해 첫 버전 범위를 넘는다.
3. **데이터베이스 기반 서비스.** 여러 기기 동기화와 장기 학습에 유리하지만 로그인과 사용자 데이터 관리가 필요해 개인용 MVP 목표와 맞지 않는다.

## 정보 구조

- 상단: 날짜, 아침 브리핑 고정 상태, 마지막 생성 시각, 수동 새로고침
- 오늘의 핵심 결론 3개: AI·반도체, 삼성전자·SK하이닉스, 부동산·대출
- 핵심 뉴스: 관련성과 영향도가 높은 이슈 묶음
- 주제 필터: 전체, AI·글로벌 기술주, 삼성전자·SK하이닉스, 부동산·대출, 관심 지역
- 참고 뉴스: 기본적으로 접어 정보 피로를 줄임
- 하단: 브리핑 방식과 개인화 원칙 안내

## 이슈 데이터 모델

각 이슈는 제목, 요약, 상세 분석, 중요도, 정서, 주제, 관련 종목·지역, 출처 목록, 중복 기사 수, 원문 링크를 가진다. 여러 기사가 같은 사건을 다루면 `clusterKey`가 같은 하나의 이슈로 묶고 출처 수와 기사 수를 표시한다.

출처는 정부·공공기관, 기업 공시·공식자료, 주요 언론, 해외 원문, 증권사 리포트, 의견·전망으로 분류한다. 신뢰도는 높음·보통·참고로 표시한다. 공식 발표와 공시는 높은 신뢰도로, 전망 기사는 참고로 표현한다.

## 중요도와 요약 깊이

- 핵심: 높은 영향도와 높은 관련성을 가진 이슈. 요약, 왜 중요한지, 긍정·부정 시나리오, 확인할 지표를 모두 노출한다.
- 중요: 요약과 왜 중요한지를 노출하며 상세 분석은 펼쳐볼 수 있다.
- 참고: 짧은 요약과 출처만 제공하고 별도 영역에 둔다.

삼성전자와 SK하이닉스 직접 이슈는 최우선 점수를 받는다. 부동산은 전국 정책을 포함하되 구리·남양주·하남·왕숙 관련 이슈를 우선 표시한다.

## 상호작용과 로컬 학습

사용자는 각 이슈에 관심 있음 또는 관심 없음을 표시할 수 있다. 선택은 브라우저 저장소에 남고 화면의 정렬 점수에 작은 가중치로만 반영된다. 명시적으로 설정된 핵심 주제는 행동 때문에 제거되지 않는다.

아침 브리핑은 최초 화면 상태를 고정한다. 수동 새로고침을 누르면 기존 이슈를 바꾸지 않고 새 이슈를 “새로 추가된 주요 뉴스”에 분리해 붙인다. 데모 MVP에서는 이 동작을 결정론적 샘플 데이터로 재현하며 실제 수집기는 같은 인터페이스로 교체할 수 있다.

## 시각 방향

경제지의 차분한 편집 디자인을 사용한다. 짙은 남색, 따뜻한 미색, 청록색을 기본으로 하고 과도한 카드형 대시보드 느낌을 피한다. 큰 결론, 읽기 쉬운 본문, 명확한 배지와 넉넉한 여백으로 계층을 만든다. 모바일에서는 한 열, 넓은 화면에서는 본문과 보조 정보가 자연스럽게 나뉜다.

## 접근성·오류 처리

모든 버튼에는 명확한 텍스트 또는 접근 가능한 이름을 제공한다. 키보드 포커스, 충분한 명암, 터치 가능한 크기, 모션 감소 설정을 지원한다. 브라우저 저장소를 사용할 수 없으면 화면은 정상 동작하되 반응이 새로고침 후 유지되지 않는다. 데이터가 비어 있으면 억지로 개수를 채우지 않고 빈 상태 문구를 보여준다.

## 테스트

- 도메인 테스트: 중복 기사 묶기, 우선순위 점수, 관심 반응 가중치, 추가 뉴스 분리
- 렌더링 테스트: 핵심 결론 3개, 핵심/참고 뉴스, 주요 관심 주제, 출처·신뢰도 표시, 제외 범위 미노출
- 빌드 검증: Cloudflare Worker 호환 프로덕션 빌드

## 제외 범위

다중 사용자, 회원가입, 이메일·푸시 알림, 저장·메모, 커뮤니티, 실시간 거래, 투자 예측, 서버 기반 행동 추적은 구현하지 않는다.
