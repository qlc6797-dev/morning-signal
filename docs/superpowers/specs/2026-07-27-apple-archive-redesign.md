# Morning Signal Apple-style Archive Redesign

## Goal

Morning Signal을 짧은 데모 화면에서 매일 읽고 지난 뉴스를 찾아볼 수 있는 개인 뉴스 리더로 확장한다. 사용자는 오늘의 핵심 브리핑을 빠르게 읽고, 왼쪽 키워드 탐색과 월별 아카이브를 사용해 관심 분야의 이전 기사를 다시 확인할 수 있어야 한다.

## Chosen Direction

Apple News와 Apple 제품 페이지에서 느껴지는 절제된 리더형 인터페이스를 사용한다. 흰색과 옅은 회색을 기본으로 하고, 넉넉한 여백, 반투명 상단바, 얇은 경계선, 큰 제목, 둥근 모서리, 제한된 파란색 강조를 적용한다. 현재의 짙은 남색 경제지 스타일과 무거운 카드 인상을 제거한다.

대안으로 검토한 잡지형 카드 배열은 시각적 개성은 강하지만 긴 기사 탐색에 불리하고, 고밀도 대시보드형은 정보량은 많지만 아침 브리핑의 편안한 읽기 목적과 맞지 않아 채택하지 않는다.

## Information Architecture

### Global navigation

- 상단에는 `오늘 브리핑`과 `월별 아카이브` 두 개의 주요 탭을 둔다.
- 현재 선택된 탭은 애플 스타일 세그먼트 컨트롤로 표시한다.
- `최신 뉴스 반영` 기능은 오늘 브리핑 탭에서 유지한다.

### Keyword navigation

- 데스크톱에서는 화면 왼쪽에 고정 사이드바를 둔다.
- 키워드는 전체, AI, 반도체, 삼성전자, SK하이닉스, 부동산, 대출, 구리·남양주·하남·왕숙으로 구성한다.
- 각 키워드 옆에는 현재 데이터에서 찾은 기사 수를 표시한다.
- 모바일에서는 고정 사이드바를 제거하고 상단 아래의 가로 스크롤 키워드 메뉴로 변환한다.
- 키워드 선택은 오늘 브리핑과 월별 아카이브 모두에 같은 방식으로 적용한다.

### Today view

- 첫 화면은 작은 상태 문구, 큰 제목, 짧은 설명으로 시작한다.
- 핵심 결론 3개는 밝은 글라스 패널 안에 배치한다.
- 핵심 기사는 한 열 리더 형식으로 보여주며 제목, 날짜, 출처, 긴 요약, 왜 중요한지, 영향 분석, 관찰 지표, 원문 링크를 제공한다.
- 참고 뉴스와 수동 갱신 뉴스는 기존 아침판과 시각적으로 구분한다.

### Monthly archive

- 2026년 5월, 6월, 7월 샘플 아카이브를 제공한다.
- 기사는 `publishedAt` 날짜를 기준으로 월별 자동 분류한다.
- 월 선택기는 최신 월부터 역순으로 보여준다.
- 선택한 월의 기사 수와 핵심 키워드를 요약해 표시한다.
- 월별 아카이브에서도 왼쪽 키워드 필터와 원문 링크가 작동한다.
- 데이터가 없는 월이나 키워드는 억지로 콘텐츠를 채우지 않고 명확한 빈 상태를 보여준다.

## Article Model and Content

각 이슈는 기존 필드에 다음 정보를 추가한다.

- `publishedAt`: 월별 분류에 사용하는 ISO 날짜
- `deck`: 제목 아래의 한 문장 설명
- `body`: 현재 요약보다 2~3배 긴 두 문단 수준의 브리핑 내용
- `takeaways`: 사용자가 기억할 핵심 포인트 목록
- `primaryUrl`: 대표 원문으로 이동하는 직접 링크

기사 카드는 대표 출처의 `primaryUrl`을 `원문 기사 보기` 버튼에 연결한다. 복수 출처 링크도 하단에 유지한다. 새 창에서 열리며 `noopener`와 `noreferrer`를 적용한다.

첫 버전은 실시간 기사 전문을 복제하지 않는다. 기존과 동일하게 샘플 브리핑과 공식 기관·기업·주요 출처 링크를 사용하며, 상세 내용은 기사 전문이 아니라 개인 브리핑용 해설로 작성한다.

## Interaction and State

- 주요 탭, 키워드, 월은 브라우저 내 상태로 관리한다.
- 관심 있음·관심 없음 설정은 기존 로컬 저장 방식을 유지한다.
- 관심 반응은 정렬의 보조 신호로만 사용하고 명시적 키워드 필터를 변경하지 않는다.
- 탭이나 월을 바꾸면 콘텐츠 제목으로 초점을 이동해 키보드 사용자에게 화면 변화를 알린다.
- 모션 감소 설정을 존중하고 전환 애니메이션은 짧은 투명도·위치 변화로 제한한다.

## Responsive Layout

- 1100px 이상: 220px 고정 키워드 사이드바와 최대 820px 리더 본문
- 760px~1099px: 좁은 사이드바와 단일 본문
- 759px 이하: 사이드바를 가로 키워드 메뉴로 전환하고 모든 기사 카드를 한 열로 표시
- 원문 버튼과 주요 제어는 최소 44px 터치 높이를 유지한다.

## Error and Empty States

- 선택한 월에 기사가 없으면 다른 월을 선택하라는 안내를 제공한다.
- 선택한 키워드 결과가 없으면 필터 초기화 버튼을 보여준다.
- 브라우저 저장소가 차단되어도 기사 탐색과 링크 열기는 정상 동작한다.
- 유효한 대표 링크가 없는 데이터는 원문 버튼을 숨기고 출처 목록만 표시한다.

## Testing

- 도메인 테스트: 날짜 기준 월별 그룹화, 최신 월 우선 정렬, 키워드별 필터, 월·키워드 결합 필터
- 렌더링 테스트: 오늘/월별 탭, 왼쪽 키워드 탐색, 2026년 5·6·7월 선택기, 긴 기사 본문, 원문 링크
- 회귀 테스트: 핵심 결론 3개, 삼성전자·SK하이닉스 우선순위, 관심 지역, 신뢰도 배지, 수동 갱신 분리
- 품질 검사: 프로덕션 빌드, 전체 Node 테스트, ESLint, Git 공백 검사

## Scope Boundaries

이번 개편에는 실제 뉴스 크롤러, 유료 뉴스 API, 기사 전문 저장, 서버 데이터베이스, 로그인, 여러 기기 동기화, 저장·메모, 푸시 알림을 추가하지 않는다. 실시간 수집은 별도 데이터 연결 단계로 남긴다.
