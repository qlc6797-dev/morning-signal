# 당일 반도체 기사 피드 설계

## 목표

Morning Signal의 반도체 영역을 한국시간 당일 기사 최대 30개로 구성한다. 각 기사는 다른 기사와 합치지 않고 독립적으로 표시하며, 한 시간 단위로 최신 목록을 다시 가져온다.

## 데이터 수집

- 서버가 반도체, HBM, 메모리, 삼성전자, SK하이닉스 등 반도체 관련 검색 RSS를 가져온다.
- 게시 시각을 `Asia/Seoul`로 변환해 오늘 날짜인 기사만 남긴다.
- 동일 URL 또는 완전히 동일한 제목만 중복 제거한다. 내용이 비슷하다는 이유로 여러 기사를 하나의 이슈로 합치지 않는다.
- 최신순으로 최대 30개를 반환한다. 당일 기사가 30개보다 적으면 이전 날짜 기사로 채우지 않는다.
- 원문 또는 피드가 제공하는 설명을 정리해 기사별 요약으로 사용한다. 설명이 없으면 내용을 추측하지 않고 요약 없음 상태를 표시한다.

## 갱신 방식

- API 응답은 한 시간 동안 캐시한다.
- 캐시 만료 뒤 첫 접속이 새 목록을 생성한다. 별도 Codex 자동 작업이나 매시간 재배포는 사용하지 않는다.
- 화면은 한 시간마다 피드를 다시 요청한다.
- `최신 뉴스 반영하기`는 사용자가 즉시 다시 확인할 수 있는 수동 요청을 보낸다.
- 수집처 장애 시 마지막으로 받은 목록을 유지하고 갱신 실패 상태와 시간을 표시한다.

## 화면

- 오늘 화면의 반도체 영역에 현재 기사 수와 마지막 갱신 시각을 표시한다.
- 기사 카드는 제목, 언론사, 게시 시각, 기사별 요약, 원문 링크를 제공한다.
- `관련 기사 N건 통합`, 통합 영향 분석, 여러 기사를 합친 결론은 라이브 반도체 목록에 표시하지 않는다.
- 로딩, 당일 기사 없음, 갱신 실패 상태를 구분한다.
- 기존 월별 아카이브와 다른 관심 분야 샘플은 유지한다.

## 안전성과 범위

- `http` 또는 `https` 원문 링크만 허용한다.
- 기사 전문을 저장하거나 복제하지 않는다.
- 로그인, 데이터베이스, 유료 뉴스 API, OpenAI API 요약은 추가하지 않는다.
- 수집처가 제공한 설명 이상의 내용을 임의로 생성하지 않는다.

## 검증

- 한국시간 당일 필터, 최신순 정렬, 30개 제한, 독립 기사 유지 테스트
- 한 시간 캐시와 수동 갱신 요청 테스트
- 기사별 제목·언론사·시각·요약·원문 링크 렌더링 테스트
- 요약 없음, 기사 없음, 수집 실패 상태 테스트
