# Morning Signal

AI·반도체 투자와 부동산 정책에서 중요한 변화만 압축해서 보여주는 개인용 아침 뉴스 브리핑 웹앱입니다.

## 핵심 기능

- 오늘의 핵심 결론 3개
- 한국시간 당일 반도체 기사 최대 30개
- 반도체 기사를 합치지 않고 기사별 요약·언론사·시각·원문 링크 제공
- 한 시간 캐시 기반 자동 갱신과 수동 새로고침
- 삼성전자·SK하이닉스 최우선 정렬
- AI·HBM·글로벌 반도체 공급망 브리핑
- 부동산 정책·대출·집값과 구리·남양주·하남·왕숙 우선 표시
- 기존 샘플 브리핑의 같은 이슈 중복 기사 통합
- 핵심 뉴스와 참고 뉴스 분리
- 출처 유형과 신뢰도 표시
- 중요 뉴스의 긍정·주의 시나리오
- 관심 있음/없음 반응을 기기 내에 저장
- 고정된 아침판을 유지하면서 수동 새로고침 이슈를 별도 추가
- 모바일 한 열, PC 두 열 반응형 화면

## 현재 데이터 범위

반도체 화면은 공개 뉴스 RSS에서 한국시간 당일 기사만 가져오며, 최신순으로 최대 30개를 보여줍니다. 당일 기사가 부족해도 이전 날짜 기사로 채우지 않습니다. 요약은 뉴스 출처가 제공한 설명을 정리한 것이며 설명이 없으면 내용을 생성하지 않습니다.

부동산과 월별 아카이브 등 나머지 영역은 화면과 분류·정렬 동작을 보여주는 샘플 브리핑입니다. 기사 전문은 저장하거나 복제하지 않고 원문 링크만 제공합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
pnpm install
pnpm dev
```

프로덕션 검증:

```bash
pnpm build
pnpm test
pnpm lint
```

## 배포

이 프로젝트는 vinext 기반 Cloudflare Worker 출력과 `.openai/hosting.json`을 사용합니다. Codex Sites에서 빌드된 버전을 저장한 뒤 비공개 또는 승인된 공개 범위로 배포할 수 있습니다.

## 주의

이 앱은 투자 또는 부동산 의사결정을 대신하지 않습니다. 표시된 내용과 외부 링크는 판단을 돕기 위한 참고 정보입니다.
